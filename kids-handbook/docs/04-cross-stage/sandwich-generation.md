# 04-1 · 三明治世代專區

> 同時照顧失智長輩 + 育兒新生兒 / 幼兒 / 學齡兒童的家庭。
> 壓力 stack 跟 trade-off 跟一般家庭不一樣，要單獨講。

---

## 為什麼三明治世代需要專章

- **後援系統不能 share**：失智者環境變動會 sundowning，不能請後援同住坐月子
- **時間排程要整合**：回診 / 接送 / 餵奶 / 換尿布 / 早晚 SOP 全部撞在一起
- **財務壓力**：長照支出 + 育兒支出 + 可能育嬰留停 → 收入降
- **空間壓力**：失智長輩需要熟悉環境，幼兒需要安全環境，兩者邊界要設計

## 跨階段的 sandwich-specific 考量

### 0-6 歲段（Tab 1-2 補充）

來源：原 `newborn-handbook` 跟 `childcare-handbook` 的「失智照護家庭專區」遷入。

- 後援評估（家有失智長輩時不能請阿嬤幫忙坐月子）
- 接送動線 vs 長輩生活圈
- 祖父母接孫可行性（認知功能評估）
- 喘息服務 + 日照中心 + 幼兒園疊合

### 6-15 歲段（接 Tab 3）

學齡孩子的 sandwich-specific：

- **她會看到爺爺奶奶的退化過程**，這是她的成長素材
- **她對「失能」的理解**，會影響她對 own / 不 own 的看法
- **不要讓她變成 emotional support 角色**（保護她當小孩的時間）
- **讓她參與照顧的方式要 age-appropriate**（小一可以陪聊天，國中可以幫量血壓，但不該替她安排「主要照顧者」位置）
