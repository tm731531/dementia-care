# 04-2-4 · Firewall 4 — 正常版本沉浸 + 程序性 firewall

> 解決的擔憂：**詐騙 / 惡意 AI / 假訓練資料。前三層的代價是踩坑可學，這層的代價可能不可逆（錢被騙、隱私洩漏、被誘拐）。**

---

## 核心 frame

Tom 自己 30 年讀書 + 工作經驗給你的不是「知識」，是 **「異常感」**：

> 你看過太多正常版本 → 異常會自己跳出來

你看到「免費送你 99% 報酬率」瞬間覺得不對勁，不是當下「判斷」它是詐騙，是它 **不符合你心裡的正常 pattern**。

**問題是：孩子沒看過正常 pattern。她沒有「不對勁」的感覺。**

而且 **教她判斷真偽走不通** —— 國小國中沒辦法判斷大部分事。

---

## 解法：兩條路並走

### 路徑 1：正常版本沉浸（被動，但累積）

不是教她「詐騙怎麼分辨」，是讓她 **看過足夠多的正常**：

- 你跟太太怎麼買東西（正常價格、正常流程）→ 看到「跳樓大拍賣免運贈送」會覺得怪
- 你跟太太怎麼跟銀行 / 醫院 / 學校打交道 → 看到「行員打電話要轉帳保管」會覺得怪
- 你跟太太怎麼判斷一篇文章（去查作者、查日期、看誰引用）→ 看到「網紅 100% 賺錢」會覺得怪

她不需要學「怎麼分辨」，她只需要 **看夠多正常**。**異常會自己跳。**

### 路徑 2：程序性 firewall（主動，不依賴判斷）

她不需要當下判斷對錯，只需要學兩條程序：

| 程序 | 對應的問題 |
|------|-----------|
| **不可逆的事 → 等一晚** | 詐騙核心是製造急迫感繞過理性。從小事練「不急著決定」（玩具明天再買、零食週末再吃），等她國高中遇到大事（情緒決定、被網友約見面、被勸入怪團體），這條肌肉會救她無數次 |
| **不確定的事 → 回家問** | 國小國中她沒有獨立判斷能力，但她可以有「**遇到不對勁先停下來問爸媽**」這套程序 |

---

## 程序性 firewall 的 prerequisite

**你跟太太必須是「她遇到不確定時第一個想回頭問的人」。**

如果：
- 她做錯被罵 → 下次不會回來問 → firewall 失效
- 她講感受被打斷 → 下次不會講 → 確認機制斷掉
- 你跟太太自己慌張 → 她學到的是慌張不是冷靜

**這個關係不是國中才開始建，是 3-12 歲累積出來的。** 現在女兒 2.5 歲，接下來 3 年（到 5.5 歲）正是建立這套信任結構的關鍵期。

**等她國中你才想「保持是她願意問的對象」就晚了。**

---

## 性質

- 這層 **代價可能不可逆**（不像前三層踩坑可學）
- 用「程序」+「沉浸」取代「判斷」
- 父母關係品質 = firewall 效力

---

## 給你跟太太的填空

我們家的「正常版本沉浸」場景：

- [ ] 我跟太太怎麼買東西時，她在旁邊看（什麼時段？）
- [ ] 我跟太太判斷一篇文章時，**出聲想**（去查 X / 看 Y）
- [ ] 我跟太太處理 ______（銀行 / 醫療 / 學校）時，她參與或旁觀

我們家的「程序性 firewall」訓練：

- [ ] 「不可逆的事 → 等一晚」從什麼小事開始（玩具？零食？）
- [ ] 「不確定的事 → 回家問」的氛圍怎麼維持（不罵 / 不打斷 / 不嘲笑）
- [ ] 我跟太太自己慌張時怎麼示範冷靜（她在旁邊看）

紀錄她「先停下來問」的時刻 → 寫到 [`../../brain/`](../../brain/)。
**那是 firewall 在 work 的證據。**
