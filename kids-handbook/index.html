💡 實戰提醒(Tom 家 2023 經驗)

  • 領了媽媽手冊立刻申請,不要等:晚申請 = 浪費前期產檢趟數
  • 排黃金路線:診所遠(如高層次超音波要去大醫院)更要用,單趟 200-300 元車資刷掉差額 100-200

  • 每月查餘額:APP 內可看,別拖到產後才發現沒用完
  • 計程車司機可能不熟:上車前先問「有合作好孕專車嗎」,沒有就換一台

💪 產後恢復

自然產

  1. 休息和康復:分娩後需休息,醫生建議數週內充分休息
  2. 疼痛管理:會陰疼痛(撕裂或側切),醫生開止痛藥按時服
  3. 產後護理:陰道清潔每天溫水 + 溫和肥皂清洗,預防感染
  4. 經血(惡露):子宮廢物 + 血液混合,使用產婦專用衛生巾,注意量 / 顏色變化異常立即回診
  5. 恢復運動:產後 1-2 週開始輕度散步,避免劇烈運動

🔪 剖腹產

剖腹產是大手術 — 體外傷口 7-10 天恢復,但體內傷口要 2 個月。2 個月內不搬重物 / 不劇烈運動 / 飲食維持高蛋白。

  1. 休息和康復:大手術需充分休息,數週內避免重體力 / 提重物 / 劇烈運動
  2. 疼痛管理:遵循醫生用藥,不要自行停藥
  3. 傷口護理 5 點:保持手術切口乾淨乾燥 / 溫和清潔(溫水 + 溫和肥皂)/ 溫和拍乾不摩擦 / 避免刺激性化妝品 / 定期更換繃帶
  4. 避免感染:傷口出現紅腫 / 滲液 / 發燒 → 立即看醫生
  5. 限制重物:康復期間避免舉重 / 重體力
  6. 適當飲食:均衡 + 高蛋白(母乳餵養更要),維生素 + 礦物質
  7. 產後體位練習:逐漸開始,加強腹部 + 核心肌肉
  8. 情感支持:產後憂鬱要找家人 / 朋友 / 心理師說

👨‍👧 出生後:爸爸 5 步政府表單

  • 元大銀行(若有)

  • 意外險

🤱 出生後:媽媽動作清單

母乳餵養 — 增加母乳的 4 招

  1. 補充水分:水是乳汁主要原料,多喝水 + 多吃蔬果 / 果汁 / 湯
  2. 避免酒精:酒精會減少母乳量
  3. 定期排出母乳(最關鍵):
    • 母乳分泌依需求,需求越多分泌越多
    • 頻繁排出 → 身體自動製造更多
    • 每側乳房擠 15-20 分鐘
    • 新生兒每 2-3 小時餵 1 次
    • 用預擠母乳餵也應每 2-3 小時擠 1 次
    • 每天約擠 8-12 次
  4. 促進母乳分泌的食材:
    • 大蒜、洋蔥、薄荷(會讓母乳味道不同,刺激寶寶想喝更多)
    • 糙米、燕麥等全穀物
    • 嘗試香草 / 茶飲前先諮詢醫師

配方乳選擇

  • 找有認證標章的
  • 選大廠牌(出問題有保障 + 比較不會 stale)
  • 從新生兒配方 → 較大嬰兒(6 個月)→ 幼兒(1 歲)分階段換

👶 寶寶體重問題

小孩體重跟超音波有 10-20% 誤差,出生後 3-5 天又會降生理性體重(約 5-10%)。

WHO / 國健署 早產兒分類(供參考,各醫院實際標準會略不同):

  • 極低體重兒:< 1,500g(通常進新生兒加護)
  • 低體重兒:1,500-2,500g(評估觀察,部分需保溫箱)
  • 正常足月:≥ 2,500g

月中收住標準:多數月子中心要求 ≥ 2,200-2,500g 且體溫穩定,各家差異大,訂房前確認。

結論:孕期維持均衡飲食 + 規律產檢,體重落在足月區間最不麻煩。具體標準以你的婦產科 / 兒科醫師為準。

水奶 vs 配方奶差異

  • 水奶:即開即喝,衛生 / 方便,但貴 + 開封後保存短
  • 配方奶:粉狀,需熱水沖泡,便宜 + 保存久,但要洗奶瓶 / 控溫
  • 外出建議帶水奶,在家用配方奶

🏫 4 種托育類型

費用、報名方式、抽籤規則完全不同。選錯類型,所有後續動作都白搞。

⚠️ 重要前提:0-2 歲跟 2-6 歲是兩套法律。「0-2 歲機構式托嬰」歸衛福部管(兒少法),「2-6 歲幼兒園」歸教育部管(幼照法)。兩套主管機關、兩套類型、兩套收費規則,下面拆兩張表看。

📊 0-2 歲(托嬰中心)— 3 類型

類型適用年齡家長實付/月(雙北一般家庭)政府補助報名/抽籤等候時間
公辦民營公托 / 社區公共托育家園 滿 2 個月 - 未滿 2 歲 約 4,000(一般)/ 約 2,000(中低收)/ 約 0(低收) 中央 7,000 / 月起 滾動式登記 + 集中抽籤 6 個月 - 1.5 年(熱區可達 2 年)
準公共托嬰中心 滿 2 個月 - 未滿 3 歲 約 5,000 - 12,000(補助後) 中央 13,000 / 月起 + 縣市加碼 各中心自辦 較公托短(熱門中心 3-6 月)
一般私立托嬰中心 滿 2 個月 - 未滿 3 歲 15,000 - 40,000+ (全額自付) 只能改領育兒津貼 5,000 各中心自辦 即時 - 半年

「非營利」在 0-2 歲層級不存在(非營利幼兒園是教育部體系,法定只收滿 2 足歲)。0-2 歲還有第 4 條路 —— 保母(居家式托育)。

📊 2-6 歲(幼兒園)— 4 類型

類型適用年齡家長月費報名方式抽籤規則等候
公立幼兒園(公幼) 2-6 歲 學費約 1,000 + 餐點代辦 1,500-2,500 各縣市統一網站 區域順位 + 抽籤 2 歲班最競爭
非營利幼兒園 2-6 歲 第 1 胎 ≤2,000 / 第 2 胎 ≤1,000 / 第 3 胎免費 新北 kid123 / 各縣市統一網站 統一電腦抽籤 中等
準公共幼兒園 2-6 歲 第 1 胎 3,000 / 第 2 胎 2,000 / 第 3 胎 1,000(法定上限) 各園自辦 各園自辦公開抽籤 中等
私立幼兒園(自費) 2-6 歲 8,000 - 50,000+ 各園自辦 名額制 即時(有錢就有位)

準公共幼兒園的 3,000 元含學費 + 雜費 + 代收代辦費,但不含延托費、保險費、交通費。

🏛 公托 / 公幼特點

  • 👍 費用最低(月費 2000-4000,含政府補助後)
  • 👍 師資穩定(教保員多為公務體系,流動率低)— 但代價是若分配到風格不合的老師幾乎不能換班
  • 👍 標準化(教學內容、餐食、安全規範統一管理)
  • 👎 名額極少,公托(0-2 歲)等候 1-3 年很正常
  • 👎 區域順位:沒設籍在該區可能根本沒抽籤資格
  • 👎 教學偏「保守」:沒有蒙氏/華德福之類的特色

🏘 非營利幼兒園特點(只有 2-6 歲)

  • 👍 費用低(第 1 胎月費約 2,000)
  • 👍 報名統一(各縣市一個網站搞定多家)
  • 👍 備取保留期長(新北非營利保留至下年留園直升前一日)
  • 👍 線上報到(不用臨櫃)
  • 👎 名額少,抽籤競爭激烈
  • 👎 不收 0-2 歲

🏢 準公共特點

📌 「準公共三兄弟」一句話釐清
  • 準公共托嬰中心(0-未滿 3 歲)— 衛福部 / 補助 13,000+ / 家長實付 5,000-12,000
  • 準公共保母(0-未滿 3 歲)— 衛福部 / 補助 13,000+ / 家長實付 5,000-12,000
  • 準公共幼兒園(2-6 歲)— 教育部 / 家長月費上限 3,000(第 1 胎)
  • 👍 費用比私立低很多 / 名額較多 / 有 0-2 歲托嬰版本 / 教學風格較多元
  • 👎 各園自辦報名(時程、地點、文件、規則全不一樣 — 累)
  • 👎 備取保留期差異大(短的 5 天,長的 4 個月,要看清楚)
  • 👎 合約期到期可能退場
⚠️ 準公共合約期到期 = 隨時可能爆價。準公共不是永久合約,而是期程制(第 3 期程 113/8 - 116/7)。期滿不自動續約、評鑑未通過者無法續約、不續約後費用立刻回到 8,000-15,000+ 月費。家長端每年 7-8 月新學年前注意園所公告。

💸 私立(自費)特點

完全自由訂價。費用從每月 8000(基本)到 50000+(雙語/特色園)都有。沒有政府補助。

  • 👍 不用抽籤,看名額即可申請(隨時可入,不限開學)
  • 👍 教學風格多元(蒙氏、華德福、雙語、森林、體育)
  • 👍 可以中途轉入
  • 👎 費用高(年費可能是準公共的 5-15 倍)
  • 👎 隱形費用多(註冊費、書本費、制服費、活動費、延托費 — 累計可能再加 30%)
  • 👎 退費規則嚴 / 師資流動率參差

📐 怎麼決定優先順序

狀況建議優先序
預算緊 + 雙薪 + 0-2 歲公托 → 準公共托嬰 → 私立托嬰
預算緊 + 雙薪 + 2-6 歲非營利 + 公幼(同期報) → 準公共 → 私立(備援)
預算寬 + 想要特定教學直接看私立(蒙氏/華德福/雙語) → 準公共補位
住偏遠地區查最近的「準公共」+ 「私立」
想全家搬家配合園所公托/公幼是首選,其他類型不用為它搬
⚠️ 不要只報一家。即使最想要 A 園,也要報 B、C、D 當保險。抽籤是運氣,沒抽中要等下一年(8 月開學前可能補不到位)。同時報 3-5 家是常態。

🎯 5W1H 評估方法論

每個家庭適合的園所不同。這 6 個維度逐一回答,不是想哪個算哪個。

👤 Who · 你家是誰

「孩子幾歲」不是 Who 的全部。Who 是整個家庭結構:

  • 家庭結構:雙薪 / 單薪 / 單親 / 多代同堂(有失智長輩參與接送嗎?)
  • 預算:每月教育預算上限是多少?
  • 接送角色:誰接、誰送、有沒有備援?
  • 孩子個性:好動 / 內向 / 過敏體質 / 有特殊需求
  • 家裡其他成員:兄弟姊妹是否同園(可能有「在園生弟妹」優先順位)

📌 隱形維度:祖父母。如果有失智長輩在家,需要評估:長輩是否能參與接送(認知功能)、長輩日照中心位置是否在接送動線上、長輩走失風險是否影響你的行程彈性。看「三明治世代專區」段落。

🏫 What · 選哪一類

決策邏輯:

  1. 先看預算(私立 vs 補助類)
  2. 再看年齡(0-2 vs 2-6)
  3. 再看時間(等得起公托嗎?)
  4. 最後看教學風格偏好

📅 When · 什麼時候動

類型關鍵時機
公托(0-2 歲)孩子出生就排隊。等候 1-3 年正常
非營利 + 公幼(2-6)每年 4 月底缺額公告 → 5 月初報名 → 5 月中抽籤
準公共各園不同,集中在 5-6 月
私立全年隨時(看名額),但 7-8 月開學潮位置最少

過了報名截止 = 直接失去資格,等下一年。各園截止日不同,排不開的話只能放棄某些園。

📍 Where · 距離與動線

步行 20 分鐘原則:

  • 地圖顯示 15 分鐘 → 實際 20 分鐘起跳(小孩腳步慢)
  • 下雨 / 颱風 / 寒流 → 30+ 分鐘或無法步行
  • 不要評估「我成人快走的時間」

接送動線評估:

  • 從家到園所(早上)
  • 從園所到工作地點(早上接續)
  • 從工作地點回園所(下午接)
  • 從園所回家(下午接續)
  • 有失智長輩家庭:加上「日照中心位置」「醫院位置」

📌 試走一遍。真的去走一次。算上紅綠燈、推車、抱孩子。把這個時間 +10 分鐘當作「能接受的上限」。超過就不要勉強(會崩潰)。

💡 Why · 教學風格

不要只看招生簡章上的標榜。問:

  • 典型一天的時間表是什麼?(自由探索 vs 結構式上課的比例)
  • 戶外活動多久一次?(每天 / 每週?)
  • 有沒有特殊課程?(雙語?才藝?)
  • 怎麼處理孩子情緒?(這題回答得好不好,反映教保理念)
  • 家長如何參與?(只看 Line 群還是真的有家長日)
⚠️ 雙語 / 全美語的法規灰色地帶。《幼兒教保及照顧服務實施準則》第 13 條第 4 款:有進行外語教學之必要者應以部分時間融入,不得以全部時間為之。意思是「全美語幼兒園」可能不符規定,各縣市查核力度不一。家長判斷方法:直接問「每天有幾小時中文活動?中文教師是誰?」
⚠️ 注音教育部明確不教,但私園可能偷教。《實施準則》第 13 條第 9 款:不得進行以精熟為目的之讀、寫、算教學。正規期是小一前 10 週才教注音。研究顯示提前死記反而在一年級造成干擾。選園要問:「大班會教注音嗎?寫字嗎?」回答「教」就違規。

🔧 How · 報名流程

  1. 準備期(報名前 2-4 週):備齊文件、排清單、跟家人達成共識
  2. 報名期(各園不同):準時遞表 / 上傳
  3. 等候期(報名後 1-2 週):資格審查、補件
  4. 抽籤日(各園不同):當天公告結果
  5. 報到期(抽中後 1-3 天):準時報到!過了就放棄正取
  6. 備取等候期(看各園公告,5/14 ~ 10/31 都有):備取保留期長的有機會

📋 看園所 Checklist

現場參觀必檢的 6 大維度。不被漂亮裝潢分心,問該問的、看該看的。

🎯 現場 30 分鐘:3 題口問 + 5 個眼睛看 + 2 試讀觀察

10 題口問實際 35-50 分鐘跑不完。改用「口問 3 題」+「眼睛看 5 個」+「試讀 2 點觀察」。

🗣 口問 3 題(別讓園所給標準答案)

  1. 今天主帶我家小孩的老師是哪位?她帶多久了?去年有沒有換過主帶?(主帶 + 異動,雙問)
  2. 孩子哭不停 / 打人,老師怎麼處理?能舉個最近發生的例子嗎?(要具體例子,不聽 SOP)
  3. 能不能讓我跟近期在讀家長(最近 1 年)聊一聊?(測園所是否有信心讓家長交流)

👀 眼睛看 5 個指標

  1. 老師眼神:跟孩子互動時是「眼睛在孩子身上」還是「看天花板等下班」?有沒有蹲下來跟孩子說話?
  2. 當下實際師生比:不問「法規 1:5」(都會說對),自己算今天現場幾位老師對幾個孩子
  3. 菜單看當天的:口頭說沒用,要看當天午餐(菜色 / 份量 / 溫度)
  4. 廚房 + 廁所:熱水區 / 利器是否隔離、廁所乾淨嗎
  5. 離園時孩子的神情:在場其他孩子被接走時是哭著要回去還是玩到不想走?(這個指標比所有口問都真)

🧪 試讀 2 點觀察(若有試讀務必試)

  1. 午睡 + 第一餐:0-3 歲孩子能否在陌生環境睡 / 吃,是最真實的訊號
  2. 家長離開 5 分鐘的反應:你假裝接電話走出去 5 分鐘,看老師如何處理孩子情緒

6 大維度詳細觀察點

🛡 安全

  • 消防 / 逃生路線清楚標示,有定期演練紀錄
  • 監視器涵蓋(室內外)+ 家長可申請調閱機制
  • 門禁:外人能否輕易進入?接送身份核對流程
  • 戶外遊樂設施有無防護(地墊、防夾)
  • 緊急狀況通報 SOP(送醫 / 走失)

👩‍🏫 師資

  • 主帶老師年資 + 流動率(問「過去 3 年換過幾位主帶」)
  • 師生比(實際 vs 法規)
  • 教師資格(幼教師執照 vs 教保員 vs 助理)
  • 進修紀錄(每年有沒有上專業課程)
  • 老師跟孩子的互動方式(蹲下、眼神接觸、聲調溫和?)

🏠 環境

  • 採光 / 通風(密閉空間是孩子生病的溫床)
  • 分區明確:活動區 / 安靜區 / 餐食區 / 廁所
  • 玩具材質(木製 vs 塑膠 / 是否定期消毒)
  • 戶外活動空間(每天是否有戶外時間)
  • 水質檢驗紀錄(看牆上公告)

🍽 餐食

  • 菜單是否公告(週菜單 / 月菜單)
  • 食材來源(在地 / 有機 / 一般)
  • 過敏處理(特殊飲食需求是否能配合)
  • 餐具消毒方式
  • 是否邀請家長試吃(信心指標)

📚 教學

  • 教學風格(蒙氏 / 華德福 / 主題式 / 雙語)— 看實際做法不看招牌
  • 一週課程表(自由活動 vs 結構式比例)
  • 戶外教學頻率
  • 家長參與機會(家長日、親子活動)
  • 學習紀錄方式(成長檔案、學期報告)

💰 隱形費用

  • 註冊費(每學期 vs 每年)
  • 書本 / 教材費
  • 制服 / 圍兜 / 寢具
  • 校外教學 / 活動費(頻率)
  • 延托費(時段 + 單價)
  • 保險費 / 家長會費 / 才藝課輔費
  • 問清楚全年總費用,不要只看月費

⚠️ 觀察園所對問題的態度。這份 checklist 50+ 項,現場 30 分鐘問不完。重點觀察是:園所能不能解釋「為什麼這樣做」,而不只是「我們有做」。對每題都無法解釋、或迴避所有實務細節,才是警訊。

8 月初開學(普遍 8/3 左右)🟢 低
9-12 月跟園所互動、評估是否續讀🟢 低

👶 0-2 歲(托嬰)的時程不同

公托不是「每年 4-6 月一波」,而是滾動式登記。出生就排,等候名單通常 1-3 年。

  • 孕期 / 出生:確認戶籍區,查該區有哪些公托 + 準公共托嬰
  • 出生 0-3 月:辦戶籍 → 立刻去公托登記排隊
  • 出生 6 個月後:確認自己預計幾月送托(影響可登記月份)
  • 送托前 2 個月:看排到第幾位 → 決定送公托還是準公共/私立
  • 送托前 1 個月:報名選定園所 + 安排試讀(很重要,試讀看孩子適應度)

🎒 4-6 歲(大班/中班/續讀)

  • 大部分孩子 2 歲入園後就留園直升到大班畢業
  • 留園直升登記通常 1-2 月,不要錯過(錯過要重抽籤)
  • 想換園的話,看新生缺額(4-5 月公告)
  • 準備上小學:大班下學期(隔年 4-5 月)看小學學區
⚠️ 預防接種紀錄影本最容易漏。所有園所都要,但很多家長到報到才發現黃卡找不到 → 衛生所補發要 1-2 週。現在就先確認在哪、影印 5 份。

📄 文件 SOP

各園需要的文件大同小異。提前備齊,錄取後不用臨時找。

📋 報名階段(一般生)

大部分準公共/私立的一般生報名只需現場填表,但到場時帶以下「正本」:

  • 孩子健保卡 正本(確認出生年月日)
  • 家長身分證 正本(確認家長身份)
  • 原子筆

💻 非營利網路報名

  • 提前在統一網站註冊帳號(別等到報名日才註冊)
  • 戶口名簿掃描檔(系統查調為主,失敗時上傳)
  • 確認手機號碼可收簡訊(補件、抽籤結果都靠簡訊)
  • 跨縣市新搬遷者:必須上傳戶口名簿(設籍未滿期者)

⚠️ 黃卡找不到怎辦?
  1. 先翻媽媽手冊和產檢資料夾(常被夾在裡面)
  2. 找不到去戶籍地衛生所補發,要帶孩子健保卡
  3. 補發要 1-2 週,不要等到報到前才辦
  4. 有些縣市可線上查接種紀錄(健保署「健康存摺」)

🎲 抽籤機制

大部分公幼/非營利/準公共都靠抽籤。備取保留期短的等於沒中,這個細節千萬要看。

🔄 標準流程

  1. 報名 — 各園規定的報名期間提交資料
  2. 資格審查 — 園方/教育局審核資料、補件通知
  3. 抽籤 — 報名人數 > 名額 才會抽。報名人數 ≤ 名額 直接全錄取
  4. 正取 + 備取公告 — 抽到正取的依序遞補,備取按抽籤順序排隊
  5. 正取生報到 — 截止日內到場/線上報到。過了就放棄正取資格
  6. 備取生遞補 — 正取沒報到 → 備取依序通知 → 直到滿額或備取保留期截止

⚠️ 順位 vs 抽籤的差別

同一園所內可能有多個順位(例:第 2 順位是教職員子女,第 3 順位是社區住戶,第 4 順位才是一般生)。順位是先後順序,前順位優先填滿,輪到一般生才開始抽籤。

典型順位範例(各園不同):

  1. 第 1 順位:特殊身份(身障、原民、低收)
  2. 第 2 順位:教職員子女、在園生兄弟姊妹
  3. 第 3 順位:社區/鄰里居民、簽約合作機構員工
  4. 第 4 順位:一般生

問清楚自己屬於第幾順位。報名前看簡章「順位」段,搞清楚自己被排在哪一順。

🚨 備取保留期 — 最容易踩的地雷

備取保留 5 天 = 跟沒中差不多。假設你是備取第 5 名,正取通常 1-2 個月內陸續報到。如果園所規定「備取保留只到報到日後 7 天」,那等於沒人放棄你就無從遞補。備取保留期短的園所,沒抽中正取就要當作沒中。

1 個月🟡 部分機會。前 3 名備取可期待

📊 同時報多家的策略

  1. 3-5 家是常態,不要只押寶一家
  2. 確認時程不衝突(報名期間、抽籤日、報到日不要撞)
  3. 排優先順序(離家最近 / 教學風格最合 / 費用最低)
  4. 抽中複數家時:選最想要的,其他家主動放棄正取(讓其他備取家庭有機會)
  5. 都沒抽中:看哪家備取保留期長,等遞補。也準備私立 plan B

🤝 留園直升

已經在園的孩子,通常隔年可以「直升」上一個年級,不用重抽。直升登記時間各園不同(通常 1-2 月),錯過就要重新抽籤。

⚠️ 常見地雷

這些是「會全盤失敗」的前提條件。看完再開始動作,不要踩過才知道。

🚨 過了報名截止 = 等下一年。大部分園所一年只開一次報名期。錯過就要等到隔年(整整 12 個月)。截止日記到 Google 行事曆 + 提醒前 3 天。
🚨 沒準時報到 = 放棄正取。抽中正取後,各園規定的報到期限(通常 2-3 天)內必須完成報到。逾期視同放棄,直接讓備取遞補。如果正在處理多家,務必把每家報到截止日列出來。
🚨 備取保留期太短 ≈ 沒中。備取保留只到 5-14 天的園所,實質上等於只看正取。評估這家園所時,要當作「沒抽中正取就是沒上」。
⚠️ 預防接種卡找不到 → 補發 1-2 週。健兒手冊黃卡是入園必備。錄取後才找會發現要去衛生所補發,可能來不及。現在就翻出來確認,影印 5 份。
⚠️ 距離評估太樂觀。Google Maps 顯示 15 分鐘 = 大人快走。實際帶孩子(小腳步、推車、抱抱)是 25-30 分。再加上下雨/颱風日 → 不可行。選園前親自走一趟。
⚠️ 多家報名期重疊。5 月初是地獄週 — 非營利網路報名(統一)+ 多家準公共現場報名(各別)同期跑。先做行事曆,把每家的「報名期間 + 報到日 + 抽籤日」全標出來。
⚠️ 順位搞錯。很多家長以為自己是第 2 順位「鄰里居民」,結果簡章寫的「鄰里」只算特定路段或里。逐字看簡章「優先順位」段,不確定就打電話問。
⚠️ 私立隱形費用(全年實際支出常多 20-40%)。月費 12,000 看起來合理,但加上註冊費、書本費、制服費、活動費、延托費、保險、才藝、冷氣費、家長會費、節慶禮金等,全年支出可能比月費高 28-71%。問清楚「全年總費用」+ 拿合約看清楚,不要只看月費。
⚠️ 教學風格名稱含糊。招牌寫「蒙特梭利」「華德福」不一定是真的(這些名稱沒法律保護,任何園所都能掛)。問實際做法:教具是否齊全、老師是否經過認證、混齡比例多少。
⚠️ 雙語/全美語的真實程度。「全美語」可能是「外師上 1 小時、其他時間中文」,也可能是「全天英文,午睡才中文」。實際聽老師對話,不是看招生海報。
⚠️ 試讀沒做。部分園所提供試讀(半天、一天、一週)。如果有提供一定要試。孩子能不能適應、跟老師合不合,只有試了才知道。
🚨 5 月地獄週全落榜怎麼辦?Plan B 三條路。抽籤是運氣,報 5 家全落榜的家庭一年都有。
  1. Plan B-1:備取等遞補(免費 + 高機率) — 備取保留期長的園所有實際機會,7-8 月才會結算。繼續每天看簡訊
  2. Plan B-2:私立補位(立刻有位 + 費用高) — 7-8 月開學前位置最少,6 月就要開始打電話問私立(月費 8K-50K)。先選一般主題式(8-15K),特色園當奢侈品
  3. Plan B-3:祖父母 / 保母過渡(短期橋接) — 等明年再戰。0-2 歲送托嬰補位(找準公共保母);3-6 歲找居家臨托或祖父母帶半年,1-2 月再辦下年留園直升

心理建設:全落榜不是你做錯了,是抽籤機制的數學現實(每園錄取率 10-30%,5 家全落榜機率約 17-60%)。

⚠️ 抽中後 4-6 月銜接期(準爸媽常忽略)。5 月抽中正取 → 6 月報到 → 8 月才開學。中間 2-4 個月要安排:
  • 0-2 歲:祖父母 / 保母 / 自己帶過渡。提前確認到入園日的銜接
  • 2-6 歲(從托嬰升幼兒園):現有托嬰可能要在 6/30 前結束,7-8 月「轉場期」要安排好
  • 準備期可做的事:練習自理(穿鞋 / 上廁所 / 自己吃飯)、調作息(午睡時段對齊)、買書包 / 餐具 / 棉被等用品
  • 陪伴期:8 月開學後第一週可能要請假(漸進入園),預先跟主管溝通

👨‍👩‍👧 三明治世代家庭專區

同時照顧失智長輩 + 幼兒的家庭。接送動線、認知資源、緊急應變 三件事要一起想。

🆘 緊急 / 撐不住 — 立即可撥的電話。1957(每天 8-22)福利諮詢 / 臨托媒合 · 1966 失智長照 / 喘息服務 · 0800-507272 家庭照顧者關懷專線 · 1925 安心專線(主照顧者心理崩潰,24h)

主流幼兒園手冊只考慮「夫妻 + 孩子」三人結構。但很多家庭實際是「失智長輩 + 夫妻 + 0-6 歲孩子」四到五人結構,選園的考量完全不同。

🧭 接送動線整合

單純夫妻只要算「家 ↔ 園所 ↔ 工作」三點。三明治家庭加上:

  • 長輩日照中心(早送 / 下午接)
  • 長輩看診(每週固定 / 不定期)
  • 居服員到府時段(白天某幾小時)
  • 長輩固定散步路線(若仍可外出)

能做的事:

  • 幼兒園選在「日照中心 → 工作」的動線上(一趟解決兩個送)
  • 避開「長輩固定外出時段」的接送(長輩可能跟孫見到產生情緒波動)
  • 接送時段固定 → 居服員時段安排不衝突

👵 祖父母接孫的可行性評估

失智早期長輩可能還能接送孫,但要評估:

  • 認知功能:能否記得時間、地址、孩子名字
  • 方向感:單獨往返園所是否會迷路
  • 應變能力:孩子哭鬧、跌倒、突然需要回家時的處理
  • 體力:推車、抱孩子、走樓梯是否吃力
  • 最重要:長輩自己願不願意(被指派照顧責任會增加壓力)
  • 輕度失智:可以「陪伴接送」(成人陪去成人陪回),不單獨負責
  • 中度失智:不建議單獨接送,但可以一起去當「長輩跟孫互動的活動」
  • 重度失智:不適合接送,但可以在家等接回來時跟孫說話、看孩子畫畫

長輩跟孫互動本身對失智是正向刺激(嗅覺/視覺/觸覺豐富)。重點是不增加長輩負擔,讓互動是樂趣不是責任。

📜 法定接送授權(很多家庭忽略)。大多數幼兒園 / 托嬰中心要求事先提交「授權接送人清單」+ 書面授權。祖父母若為固定接送人,必須在入園時就書面授權。若有失智長輩單日認知波動,園所如何判斷接送是否安全也需事先約定 SOP。建議入園面談就釐清這點。

🆘 緊急狀況預演

三明治家庭最怕「兩邊同時出狀況」。預先想清楚:

  • 長輩半夜送醫,白天孩子怎麼接?(備援接送名單:配偶 / 鄰居 / 教保員家送 / 暫托)
  • 孩子在園所發燒要接,你正陪長輩看診?(備援名單)
  • 長輩走失,你在園所路上?(分流原則:孩子是當下最緊急,長輩有警察)
  • 夫妻有一人發燒/出差,單一照顧者撐多久?(同時照顧 2 個失能者的極限是 24-48 小時)

📌 備援名單:至少 2 個人能緊急接孩子(寫在園所聯絡卡上),並讓他們知道。配偶 / 親戚 / 鄰居 / 朋友 / 居服員 / 教保員都可以。

🎯 選園 checklist(失智家庭專屬)

在一般 checklist 之外,額外要看:

  • 接送動線是否經過日照中心 / 長輩會去的地方

她沒有大人的 30 年讀書 + 工作經驗 base,她不知道「不對勁」的感覺長什麼樣。

但你也沒辦法永遠盯著她用 AI 的每一句話。你要的能力是 她使用前就知道風險。

  1. 她要 own 自己的問題(見 Tab 4 的「精神核心」跟「Ownership 怎麼培養」)
  2. 你跟另一半當 4 層 firewall(見 Tab 4 的 4 個 firewall 章節)

建立第一條 baseline

主要任務:讓她有一件事「熟到無聊」

具體做法

  • 保護一個動手領域 —— 種菜、養蝦、烹飪、修補、樂器、運動。至少一個,不要 AI 介入,不要父母代勞。這個領域長出來的不是技能,是「我自己的尺」。
  • AI 不要她直接接觸 —— 她有問題回家問你跟另一半。
  • 練「結構化描述」 —— 每天聊:「今天為什麼跟同學吵架?你預期他會怎樣?他實際怎樣?差在哪?」
  • 你跟另一半自己決策時出聲想 —— 她在旁邊吸收「歸因」這個姿勢,比你直接教她更有效。

階段 2 · 9-11 歲 · 小三到小五

鎖知識順序 + 開始接觸 AI 但有護欄

主要任務:建立「碰 AI 之前先碰原典」的順序感

歷史 / 文學

課本講三國 → 先讀課本講的版本 → 讀羅貫中節選或漫畫 → 這時候才可以問 AI「其他人是怎麼講三國的」。

反過來(先問 AI → 再讀課本)會失去「主流說法」的定錨。她會以為每個版本平等,無法判斷哪個是學校在考的。

自然科學

學校課本基礎:物理 100 年沒變、化學 50 年沒變、基礎生物 30 年沒變 —— 這些用傳統教科書就夠。AI 只用來「擴展例子」(這個原理還有什麼應用),不用來「取代課本」。

科學前沿(哪份期刊被撤、AI 訓練偏見)是 大學以後 的事。小學國中提早教,孩子吃不下。

AI 使用三規則

  1. 不可逆的事 → 等一晚再決定
  2. 不確定的事 → 回家問
  3. 給 AI 講 context 前先想「我為什麼問?」

持續做的事

6-8 階段建立的 baseline 領域繼續保護,不要因為作業變多就放棄。Baseline 是十年累積的,斷掉一年要重新長。

階段 3 · 12-15 歲 · 小六到國中

學會 own 自己的 AI 使用

主要任務:規則從「我們替你管」轉成「我們陪你想」

具體做法

  • 練習在問之前先描述自己處境:「我有 X,看到 Y,想達到 Z,預期 W」。有這個描述,AI 答案的品質才會配得上她的問題。
  • 詐騙警覺:不是教她分辨,是讓她看夠多正常 pattern。你跟另一半怎麼買東西、跟銀行打交道、判斷一篇文章 —— 她在旁邊吸收「正常版本」,異常自己會跳出來。
  • 父母當「她遇到不確定時第一個想回頭問的人」。這個關係 不是國中才開始建,是 3-12 歲累積出來的。等她國中你才想「保持是她願意問的對象」就晚了。

關鍵:別罵錯誤,會直接破壞 firewall。

她做錯被罵 → 下次不會回來問 → firewall 失效。她講感受被打斷 → 下次不講 → 確認機制斷掉。父母自己慌張 → 她學到的是慌張不是冷靜。

該禁 AI 嗎?該幾歲開始用?

不該禁。也不該追求「越早用越好」。真正的問題不是時間,是 ownership。

她每用 AI 一次,你跟另一半可以問她三個問題:

  1. 你問之前自己有沒有想?
  2. 答案你信不信?為什麼信?
  3. 如果這個答案不對,你怎麼會發現?

她答得出來 → 用 AI 沒問題。她答不出來 → 還沒準備好,退回去重練 ownership。

失敗訊號(警報)

看到這些訊號時 不是罵她,是回去檢視 4 層 firewall 哪一層沒做好:

訊號對應的 firewall 沒做好
她的回答開始「複製 AI 的語氣」Ownership 在流失(她在當傳輸帶)
她對「為什麼」沒興趣只想要「答案」Baseline 沒建立,或被 AI 吃掉
她拒絕在你面前用 AI可問對象 沒建立 —— 她沒信任空間
她說「AI 說的,所以對」結構化描述 沒練,她沒「我問之前先想」的習慣
她照 AI 給的策略執行然後踩坑、不知道為什麼結構化描述 + Ownership 都沒長 —— 她沒「我的問題」的感覺

精神核心:照顧但不替代

照顧但不替代。每個家人都要保持 own 自己。

對女兒:

  • 0-6 歲:照顧她,同時保護她「熟到無聊」的時間,讓她自己建立 baseline。
  • 6-15 歲:照顧她,同時不替她想答案,讓她 own 自己的問題。
  • 16 歲後:scaffolding 拆光,她自己 own。

對你跟另一半自己:

  • 協作但各自 own 自己的時間 / 注意力 / 健康。
  • 不替對方做決定。

為什麼這個是核心

孩子的成長路徑跟 AI 時代有兩個關鍵 tension:

Tension 1:父母想幫 vs 孩子要長

「我幫她做比較快」是每個家長都會遇到的瞬間。但長期下來孩子把「動腦」整個外包出去 ——

學齡前外包給父母,學齡後外包給 AI。外包對象變了,但 ownership 沒長出來。

Tension 2:AI 隨手可得 vs 她要自己建立判斷力

AI 工具多如牛毛,孩子隨手就問 AI。大多數答案是對的,但只要有一個是錯的、甚至是有心的詐騙,她該如何避開、甚至怎麼知道是錯的?

她沒有大人的 30 年讀書 + 工作經驗 base,她不知道「不對勁」的感覺長什麼樣。

Ownership 怎麼培養

大人用 AI 跟孩子用 AI 的差異:

大人用 AI孩子用 AI 的失敗模式
大人 own 問題 → AI 是工具AI own 問題 → 孩子變成執行者
知道要問什麼、為什麼問、答案要怎麼接不知道為什麼問,只是「我有問題就丟 AI」
答案不對勁會 reject(「這不適合我的狀況」)答案不對勁也接受(「反正是 AI 說的」)

大人的「使用前就知道風險」這個能力,不是判斷力,是 own 問題的本能:問之前已經知道「這是我的問題、為了我自己」。所以答案不適配瞬間有感。

孩子的核心問題:她沒有 own 問題的感覺,她變成「AI 跟她之間的傳輸帶」。

培養方法只有一件事:不替她解決問題

具體場景(每天都會發生):

  • 她問「為什麼」→ 不直接給答案,回「你覺得呢?」
  • 她遇到困難 → 不直接救她,問「你想怎麼辦?」
  • 她做選擇 → 不替她選,問「你想要什麼?」
  • 她生氣 → 不替她解釋情緒,問「你怎麼了?」

每一次「我幫她做比較快」的時刻,都是把她的 ownership 外包一次。

AI 不是新問題,AI 是既有問題的放大版。

學齡前外包給父母,學齡後就外包給 AI。她到 16 歲面對 AI 的姿勢,現在就在決定了。

Firewall 1 · Baseline(熟到無聊)

解決的擔憂:AI 把所有事都做到「夠好」這個程度,孩子永遠不會深入一件事到習慣,永遠 build 不出 baseline。沒有 baseline,後面整條好奇心機制都不會啟動。

核心 frame

大人能對任何新事物「分辨好壞」是因為大人有過深入做一件事的經驗。在那一件事上做到習慣 → 看到新事物時自然會比較 → 自動產生「咦這個不對勁」或「咦這個比較快」的感覺。

關鍵不是「學了新技能」,是 那個對比的瞬間。沒有 baseline 就沒有那個瞬間。

元素有 baseline 的大人沒 baseline 的小孩
baseline在某件事做到習慣沒做過任何一件事到「習慣」的程度
驚奇 / 偏差看到新東西自動跟舊的比較沒 baseline 就沒「咦」
訊號客觀可衡量(時間、效率、$)身體訊號:行/不行、快/慢、卡/不卡

AI 不是搶走答案,是 搶走「枯燥到習慣」那段時間。

具體做法

保護 1-2 個「她可以完整 own + 動手 + AI 介入不了」的領域。候選領域(純舉例,請挑你家做得到的):

  • 種植物 / 種菜(可以接上 garden-handbook)
  • 養活的生物(魚、蝦、蠶、烏龜)—— 死了就是死了,AI 救不回來
  • 烹飪(從生到熟,火、刀、調味,全部物理訊號)
  • 修補(玩具、腳踏車、衣服)
  • 樂器或某項運動(重複 → 身體訊號 → 可衡量進步)

這個循環要保護的是:baseline → 動手 → 預期 → 驗證 → 修正。

性質

  • AI 介入不了
  • 父母也代勞不了(代勞就沒有身體訊號)
  • 失敗有真實後果(魚會死、菜會枯、麵會燒焦)
  • 重複到「熟到無聊」是 feature 不是 bug

Firewall 2 · 鎖順序(傳統教材 → AI)

解決的擔憂:AI 時代每個孩子問 AI 答案不完全一樣,沒有審定機構,答案會飄。「我以為大家都這樣想」這東西消失了。她沒有共享的版本可以站著。

以前 vs 現在

  • 以前:課本 = 教育部審定 = 全國共享的 base。24 史 = 官方史 = 學術共識。課本可能爛,但 大家共享同一份爛,才能討論「我覺得這部分有問題」。
  • AI 時代壞掉的:沒有審定機構,每個孩子問 AI 答案會飄(model 版本、prompt 差異)。沒有一個可以 anchor 的點。

解法不是「教她驗證」,是 管順序。

具體做法

傳統教材是 baseline 來源,AI 是擴展,順序不可顛倒。

場景對的順序錯的順序
三國 課本講 → 羅貫中節選或漫畫 → 這時候才問 AI「其他說法」 先問 AI → 沒定錨 → 不知道哪個主流
自然科學 課本基礎(物理 100 年沒變、化學 50 年沒變)→ AI 只擴展例子 先問 AI → AI 跟不上 / 帶髒資料
歷史人物 教科書 → 維基百科 → 紀錄片 → AI 各種說法 先 TikTok / AI 短影音 → 後面學的版本變不掉這個 anchor

問題是國小生不會自己照順序。這就是你跟另一半的工作:替她鎖先後順序,不是禁 AI、不是教驗證。

科學前沿的處理

擔心「期刊後打前、AI 被髒資料訓練歪」對小學國中 過早擔心。她那階段需要的是基礎物理化學生物(30-50 年沒過時的部分)。前沿批判(哪份期刊被撤、AI 訓練偏見)是 大學以後 的事。國小國中提早教,孩子吃不下。

Firewall 3 · 結構化描述(輸入端有自覺)

解決的擔憂:AI 給的答案是 generic 的,context 被拿掉了。孩子直接套用 → 踩坑,而且不知道為什麼踩。

核心 frame

舉例:AI 給「布林通道 80/20」策略 —— generic,但 boundary 被拿掉。適合大盤 / 週期性股,不適合個股。孩子套用 → 踩坑 → 不知道為什麼踩。

「不知道為什麼踩」比踩坑更可怕,會導致:怪 AI、怪自己、怪運氣 → 全部不信任 → 虛無。

大人為什麼能歸因

大人能歸因,是因為 大人知道自己在做什麼:寫了 code 知道在哪一層、看到時間數字有可量化訊號、失敗後能拆「哦原來這層慢」。

孩子拿 AI 的策略就用,他 根本不知道自己在做什麼(他只是執行)。失敗了 沒有任何資料可以拆 —— black box 進、black box 出。

所以問題不是「驗證輸出」,是 「輸入端要有自覺」。

具體做法

在用 AI 之前,她要會描述:

我有 X、我看到 Y、我想達到 Z、我預期 W 會發生。

有這個描述:才能 正確問 AI(AI 答案的品質取決於 prompt 品質),才能 事後歸因(我哪個前提錯了)。

怎麼練(不是教,是浸泡)

這個能力不能等到要投資 / 做大事才練。要從 小事 練起:

場景練什麼
描述今天為什麼跟同學吵架不是情緒,是事件 + 期待 + 落差
描述一個玩具壞掉的原因前提、行為、結果
描述一次出遊「預期 X、結果 Y」預期 vs 實際差在哪
描述為什麼喜歡某個食物把模糊感覺結構化

最強的學習途徑是模仿。

你跟另一半自己決策時 出聲想(「我們以為這家餐廳會好吃 → 結果不好吃 → 下次怎麼判斷?」),孩子會把「歸因」當空氣吸進去。她那個能力不是教出來的,是聽你們講出來的。

Firewall 4 · 正常版本沉浸 + 程序性 firewall

解決的擔憂:詐騙 / 惡意 AI / 假訓練資料。前三層的代價是踩坑可學,這層的代價可能 不可逆(錢被騙、隱私洩漏、被誘拐)。

核心 frame

大人 30 年讀書 + 工作經驗給的不是「知識」,是 「異常感」:

看過太多正常版本 → 異常會自己跳出來

看到「免費送你 99% 報酬率」瞬間覺得不對勁,不是當下「判斷」它是詐騙,是它 不符合心裡的正常 pattern。

問題是:孩子沒看過正常 pattern。她沒有「不對勁」的感覺。

而且 教她判斷真偽走不通 —— 國小國中沒辦法判斷大部分事。

解法:兩條路並走

路徑 1:正常版本沉浸(被動,但累積)

不是教她「詐騙怎麼分辨」,是讓她 看過足夠多的正常:

  • 你跟另一半怎麼買東西(正常價格、正常流程)→ 看到「跳樓大拍賣免運贈送」會覺得怪
  • 你跟另一半怎麼跟銀行 / 醫院 / 學校打交道 → 看到「行員打電話要轉帳保管」會覺得怪
  • 你跟另一半怎麼判斷一篇文章(去查作者、查日期、看誰引用)→ 看到「網紅 100% 賺錢」會覺得怪

她不需要學「怎麼分辨」,她只需要 看夠多正常。異常會自己跳。

路徑 2:程序性 firewall(主動,不依賴判斷)

她不需要當下判斷對錯,只需要學兩條程序:

程序對應的問題
不可逆的事 → 等一晚 詐騙核心是製造急迫感繞過理性。從小事練「不急著決定」(玩具明天再買、零食週末再吃),等她國高中遇到大事(情緒決定、被網友約見面、被勸入怪團體),這條肌肉會救她無數次
不確定的事 → 回家問 國小國中她沒有獨立判斷能力,但她可以有「遇到不對勁先停下來問爸媽」這套程序

程序性 firewall 的 prerequisite

你跟另一半必須是「她遇到不確定時第一個想回頭問的人」。

她做錯被罵 → 下次不會回來問 → firewall 失效。

她講感受被打斷 → 下次不會講 → 確認機制斷掉。

父母自己慌張 → 她學到的是慌張不是冷靜。

這個關係 不是國中才開始建,是 3-12 歲累積出來的。等她國中你才想「保持是她願意問的對象」就晚了。

三明治世代專區

同時照顧失智長輩 + 育兒新生兒 / 幼兒 / 學齡兒童的家庭。壓力 stack 跟 trade-off 跟一般家庭不一樣,要單獨講。

為什麼需要專章

  • 後援系統不能 share:失智者環境變動會 sundowning,不能請後援同住坐月子
  • 時間排程要整合:回診 / 接送 / 餵奶 / 換尿布 / 早晚 SOP 全部撞在一起
  • 財務壓力:長照支出 + 育兒支出 + 可能育嬰留停 → 收入降
  • 空間壓力:失智長輩需要熟悉環境,幼兒需要安全環境,兩者邊界要設計

學齡孩子的 sandwich-specific 考量

  • 她會看到爺爺奶奶的退化過程,這是她的成長素材,不要遮蔽
  • 她對「失能」的理解,會影響她對 own / 不 own 的看法
  • 不要讓她變成 emotional support 角色(保護她當小孩的時間)
  • 讓她參與照顧的方式要 age-appropriate(小一可以陪聊天,國中可以幫量血壓,但不該替她安排「主要照顧者」位置)

「讓整個家忙起來」這個 mission 不該包含你跟另一半一刻不停。

每週留一個下午全關 —— 不寫 code、不寫家事、不規劃 feature。陪孩子、發呆、睡覺都行。你倒下 = 整個三明治結構崩塌。不是悲觀,是工程現實。

家庭紀錄循環

這本手冊只給 frame,具體場景跟踩坑紀錄是你跟另一半累積。建議三層節奏:

  • 每週一個切片 — 紀錄這禮拜發生什麼場景、誰怎麼回應、事後想「我替她做了,還是讓她做?」
  • 每月對齊一次 — 你跟另一半一起翻週紀錄,找「我們兩個處理同一場景不一致」的地方校準
  • 每年回顧一次 — 看 ownership 的成長軌跡(不是技能進步),看 scaffolding 哪些可以拆了

這個循環的具體格式跟引導,放在這個專案的 docs/brain/、docs/skill/、docs/review/ 三個資料夾的 README,供你跟另一半參考。

這本手冊本身就在示範 ownership。

等女兒大一點,她會看到爸媽真的有在「自己想怎麼養小孩」這件事 —— 不是抄別人、不是問 AI。她從你們身上學到「自己 own 自己的事」這個姿勢,比任何方法論教得都深。

時間軸

階段你跟另一半她
現在到 12 歲當 4 層 firewall + 每天練 ownership在 firewall 保護下慢慢長
國中到高中scaffolding 慢慢拆own 越來越多
大學以後scaffolding 拆光自己 own 全部
