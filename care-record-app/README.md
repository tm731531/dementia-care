# 照護紀錄 App（care-record-app）

給照顧家人的家庭用的**離線**紀錄工具。用**講的**記下每天的狀況，回診時把整段時間的趨勢和事件
一次呈現給醫生看。資料只存在你手機裡，不上任何雲端。

> 狀態：設計已定案，實作計畫進行中。設計文件見
> `docs/superpowers/specs/2026-07-23-family-app-design.md`。

## 這個 App 做什麼

- **用講的記錄**：對著手機說今天發生的事（例如「精神穩定，午餐吃一半，下午走一走，晚上睡得好」），
  App 在**手機本機**把語音轉成文字，你看一眼、需要才改。不用打字。
- **點選每日狀況**：睡眠、三餐、排泄、活動…等項目點一下就好，自動整理成趨勢圖。
- **拍照存證（選配）**：想留白板/現場照片可以拍，存在同一筆紀錄裡。
- **回診給醫生看**：累積一段時間後，產出一份**乾淨的文字 + 趨勢圖**（可存成單檔網頁或 PDF），
  醫生一眼讀完，不用一張張翻照片。
- **兩台手機共享**：你在自己手機記，照顧者（如外勞）在他手機記，把資料匯出成一個檔互傳、匯入合併，
  帶去診間的人手機上就有完整紀錄。

## 為什麼這樣設計

- **資料不出手機**：健康照護資料很敏感，這個 App 不上傳、不需要帳號、不需要申請任何金鑰。
  你要分享（例如用 LINE 或傳輸線把檔案傳給別人）是你自己決定的動作。
- **不用打字**：照顧已經夠累，記錄用講的、用點的，不跟鍵盤搏鬥。
- **不靠手寫辨識**：實測過拍照自動辨識手寫中文只有六成、還常把重要的字認錯（把某個日常詞
  認成形狀相近的常見字），會誤導醫生。所以改用語音——清楚的國語辨識準得多。
- **解鎖用臉/指紋**：打開 App 要刷臉或指紋，別人拿了你手機也看不到病人的個資；日常不用打密碼。
